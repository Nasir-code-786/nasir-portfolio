# Nasir Khan — Portfolio

Personal portfolio site for Nasir Khan, Full Stack / MERN developer.

## Development

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
npm run preview
```

## Content

Site content lives in `public/data/`. Update `profile.json`, section files under `public/data/sections/`, and `settings.json` to change what appears on the site.
